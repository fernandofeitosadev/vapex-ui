# Vapex UI

Native Android application for the Vapex Cloud platform, providing cloud service management, monitoring, and an intuitive mobile experience.

## Features

- Cloud service management
- Real-time monitoring
- Modern Android interface
- Integration with Vapex Cloud infrastructure
- Optimized mobile experience

## Tech Stack

- Java
- Android SDK
- Gradle
